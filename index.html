Agent skills for people on a usage cap.

My Claude Code skills, straight from my ~/.claude. I'm on a Pro plan, and I kept running out of usage by midweek. Not on thinking, on legwork. These skills move that legwork somewhere cheaper and keep my best model for the decisions.

Every one is manual: you type the slash command, nothing fires on its own. They're small, readable and easy to bend to your own setup. Fork them.

npx skills add moneytosms/skills

Why these skills exist

Each one fixes a way I was wasting usage. Problem first, then the fix.

#1: I'm burning my limit on grep and file reading

“The three great virtues of a programmer: laziness, impatience, and hubris.”

Larry Wall, Programming Perl

The Problem. Half of a coding session is legwork: summarize this file, find every use of that function, explain this log. My best model does it at full price, and on a Pro plan that's the week's limit gone by Wednesday.

The Fix is /offload. It hands one low-judgment task to a model that isn't Claude: Codex on gpt-6-luna, Antigravity on Gemini Flash, or a free opencode model for public repos. Claude writes the prompt, reads a short answer back, and spot-checks the file:line refs.

/offload →codex→agy→free model

Summarizing a Hyprland config: 50s on gpt-6-luna. Claude read a 10-line answer, not the files.

#2: Big tasks eat my best model

“Adding manpower to a late software project makes it later.”

Fred Brooks, The Mythical Man-Month

The Problem. A multi-ticket change means research, reading, editing and test runs. If the expensive model does all of it, it spends its context on file dumps instead of decisions.

The Fix is /delegate. It keeps the current model as the orchestrator: it plans, asks you questions after recon, and reviews every diff. Headless Haiku workers do the legwork in parallel, each editor in its own git worktree with files it alone owns, so more workers don't mean more collisions.

/delegate →haiku scouts→haiku editors→verifier

A lean worker starts at about 5k tokens of context instead of about 36k for a full subagent.

#3: My agent keeps making the same mistakes

“Those who cannot remember the past are condemned to repeat it.”

George Santayana, The Life of Reason

The Problem. The same failed command, the same retry loop, the same correction I typed last week. Every repeat costs tokens, and memory files grow until nobody reads them.

The Fix is /recall. It mines past sessions for failed and blocked tool calls, retry loops, heavy sessions and your corrections. Cheap scripts count, Haiku reads, Claude judges. You get a ranked, evidence-backed report and it writes only the fixes you approve, within line budgets.

/recall →scripts count→haiku reads→you approve

Every proposal cites a count and the sessions it came from. No evidence, no proposal.

#4: My machine is slow and I don't know why

“Premature optimization is the root of all evil.”

Donald Knuth, Structured Programming with go to Statements

The Problem. Crashes, a full disk, slow boot. Guessing at fixes wastes a session, and a wrong deletion costs far more than a slow audit.

The Fix is /tuneup. It sends a swarm of read-only Haiku agents over hardware, firmware, crash logs, disk, software and services on Linux, macOS or Windows. You get a ranked report with safety tiers, then only the fixes you approve, each previewed and measured.

/tuneup →read-only haiku→ranked report→approved fixes

Audit first, change nothing until you say which items.

Other skills I use

  • /project-showcase Turns a repo into a landing page, a searchable guide, a redesigned README and repo metadata. This site is its output.
  • /study-notes-builder Builds one polished PDF of exam-oriented study notes from lecture slides, notes or a topic list, with Typst.

Installation (30-second setup)

Claude Code plugin updates itself 
/plugin install moneytosms-skills --marketplace moneytosms/skills

Or from your shell: claude plugin marketplace add moneytosms/skills, then claude plugin install moneytosms-skills@moneytosms.

Any agent, editable files manual updates 
npx skills add moneytosms/skills

One skill only: npx skills add moneytosms/skills --skill offload.

By hand 
git clone https://github.com/moneytosms/skills
ln -s "$PWD/skills/skills/offload" ~/.claude/skills/offload

/offload needs the backends it calls: codex (logged in), agy or opencode. The others need only Claude Code.
